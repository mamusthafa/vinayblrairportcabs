The primary objective is to generate direct customer enquiries and bookings for airport transportation between Bengaluru city and Kempegowda International Airport (BLR).

### How the common files work

The developer should use `default.html` as the master layout, containing:

```

<!DOCTYPE html>
<html lang="en-IN">
<head>
  <meta charset="utf-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">

  <title>{{ page.title | escape }}</title>
  <meta name="description"
        content="{{ page.description | escape }}">
  <link rel="canonical"
        href="{{ page.url | absolute_url }}">

  <link rel="stylesheet"
        href="{{ '/assets/css/main.css' | relative_url }}">
</head>

<body>
  {% include header.html %}

  <main id="main-content">
    {{ content }}
  </main>

  {% include footer.html %}
  {% include sticky-cta.html %}

  <script defer
    src="{{ '/assets/js/main.js' | relative_url }}">
  </script>
</body>
</html>

```

Each content page specifies its own metadata and layout through Jekyll front matter.

This solution gives you:

- One shared header across every page.
- One shared footer across every page.
- One central business information file.
- Reusable booking and CTA components.
- Individual SEO metadata for each page.
- Pre-rendered HTML that works without JavaScript.
- Easy maintenance as the site grows.

For contact number changes, update the central `business.yml` file and regenerate the static site. Do not hardcode business contact information across every page.
